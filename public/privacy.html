Hold The Room — Privacy Policy

Last updated: 20 October 2026

Hold The Room (HTR) is a private assistant run by its owner on a server the owner controls. It is not offered to the public, and each install serves one owner.

What HTR accesses

With the owner's Google consent, HTR reads the owner's Gmail and Google Calendar, sends email from the owner's account, and creates or moves events on the owner's primary calendar. It sends mail and writes calendar events only after the owner approves each one.

Where data goes

Data read from Google is stored on the owner's own server and used only to draft replies, proposals and calendar views for the owner. Drafting text may be processed by the AI model provider the owner has configured. HTR does not sell data, share it with advertisers, or use it for any other purpose.

Google user data

HTR's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke HTR's access at any time at myaccount.google.com/permissions and delete the data by removing the install.
